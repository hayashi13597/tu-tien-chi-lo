> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Xây dựng vòng lặp bí cảnh idle tám nhánh, kho nguyên liệu, tám công thức luyện đan offline và nâng cấp công pháp bằng Linh Thạch + nguyên liệu, chạy song song với tu luyện hiện tại.

**Architecture:** Giữ Clean Architecture hiện có và thêm các module domain `materials`, `alchemy`, `combat`, `expedition`. Dùng các bảng riêng cho nguyên liệu, queue và expedition; không migrate Pill/CongPhap sang item engine tổng quát. Server resolve timer lazy, snapshot combat khi bắt đầu chuyến, và dùng transaction/compare-and-set cho mọi tiêu hao và cấp thưởng.

**Tech Stack:** Node.js, Express, TypeScript, Prisma 5, PostgreSQL, Vitest, Next.js 16, React 19, GSAP, Biome.
